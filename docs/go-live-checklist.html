Configurazione server
Richiesto
✓
PHP 8.1+ installato
Con le estensioni: pdo_mysql, mbstring, openssl, curl
✓
Document root → public/
Il webserver deve puntare alla sottocartella public/, non alla root del progetto
✓
HTTPS abilitato con certificato valido
Let's Encrypt è gratuito e sufficiente. Meta richiede HTTPS per i webhook.
✓
.env non accessibile via web
Il file deve trovarsi fuori da public/ — verificare che il webserver restituisca 403 o 404 su /env
✓
Permessi .env impostati a 600
chmod 600 .env — solo il processo PHP può leggerlo e scriverlo
✓
Cartella logs/ scrivibile
Il processo PHP deve poter scrivere nella cartella logs/ del progetto
⚙️
Configurazione .env
Richiesto
✓
APP_URL impostato correttamente
Es. https://moderation.sanmarinortv.sm — senza slash finale
✓
APP_SECRET impostato (64 char random)
Genera con: php -r "echo bin2hex(random_bytes(32));"
✓
APP_ENV=production
Non lasciare development in produzione — disabilita i verbose error output
✓
Credenziali DB configurate
DB_HOST, DB_DATABASE, DB_USERNAME, DB_PASSWORD
✓
ANTHROPIC_API_KEY impostato
Oppure configurato dalla dashboard Impostazioni → Integrazione Claude AI
✓
META_APP_ID e META_APP_SECRET impostati
Da Settings → Basic nella dashboard Meta for Developers
✓
META_WEBHOOK_VERIFY_TOKEN impostato
Valore casuale scelto da te — distinto da APP_SECRET. Usato per la verifica webhook.
✓
OAUTH_ALLOWED_EMAIL_DOMAINS impostato
Es. sanmarinortv.sm — fortemente raccomandato per limitare il login alle email dell'organizzazione
✓
Almeno un provider OAuth configurato
Google, Meta, o Microsoft — oppure utente locale creato via SQL

Sicurezza rete

Auto-deploy GitHub
Opzionale
✓
GITHUB_WEBHOOK_SECRET impostato nel .env
Genera con: php -r "echo bin2hex(random_bytes(24));"
✓
Webhook configurato su GitHub
Settings → Webhooks → URL: /webhook/github, stesso secret, content type: application/json
✓
GITHUB_WEBHOOK_BRANCH=main
Solo i push al branch configurato attivano il git pull automatico

Retention dati GDPR
Opzionale
✓
data_retention_days configurato nelle Impostazioni
Impostazioni → Retention dati. 0 = disabilitato. Es. 90 giorni.
✓
Cron job configurato sul server
0 3 * * * php /percorso/bin/retention-purge.php — ogni notte alle 3:00
